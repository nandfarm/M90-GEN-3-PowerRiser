# M90-GEN-3-PowerRiser
M90 GEN 3+ PowerRiser – NVMe Expansion board for Lenovo Tiny 7 Series M90q Gen 3 and above


#Status. This is a work in progres project.

 - Power supply is stable up to 75W.
 - SD Card reader works as expected
 - PCIe works as expected only for x8 or above. Does not work for x4 or x1 due to the lane reversal on the MB.
 - M.2 slot TBD.
